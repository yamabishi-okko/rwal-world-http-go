## 86 WebRTC — DataChannel チャット体験
このフォルダは、WebRTC の DataChannel を使ってブラウザ同士でチャットする最小デモです。
サーバはシグナリング（接続情報の交換）だけを担当し、実際のメッセージは P2P 通信でやりとりされます。

### 前提
Go 1.20+
モダンブラウザ（Chrome / Firefox 推奨）

### このフォルダに含まれるファイル:
server.go — シグナリングサーバ（WebSocket）
public/index.html — チャット画面
public/main.js — WebRTC 接続と DataChannel の制御

### 起動
cd ch08/86_webrtc
go run .
アクセス: http://localhost:18888

### 使い方
ブラウザを 2 枚開く（同じ PC の別タブでもOK）
片方でメッセージを入力 → もう片方にリアルタイムで届く
吹き出しスタイルで表示:
自分の発言 → 水色（右側）
相手の発言 → 黄緑（左側）
システムメッセージ → グレー（中央）
システムメッセージ（例）
✅ シグナリング接続しました
📩 オファー受信 → アンサー送信
📩 アンサー受信
🔗 データチャネル開通
⏹ データチャネル閉鎖

### ファイル同士のつながり（会話風）
💻 ブラウザ (index.html + main.js)
「ユーザーがメッセージ入力したよ！ send() で DataChannel に投げるね！」
│
▼
🌐 シグナリングサーバ (server.go)
「了解！最初の接続情報（Offer/Answer と ICE）を交換するよ。
でも実際のチャットメッセージは私を通らないで、ブラウザ同士で直接やり取りしてね！」
│
▼
💻 もう一方のブラウザ
「受け取った！相手の発言を黄緑の吹き出しで表示するね！」

### 実際の流れ（例）
ユーザーAが「やりますか？」を送信
水色の吹き出しで右側に表示
DataChannel を通じてユーザーBのブラウザへ届く
黄緑の吹き出しで左側に表示
システムが状況を報告
中央に「✅ シグナリング接続しました」「🔗 チャネル開通」などがグレー表示

# 🌙暗号化アルゴリズム ベンチマークテスト

このプログラムは **RSA** と **AES** の暗号化・復号化処理の性能を比較するためのベンチマークテストを提供します。  
Go の標準ライブラリ（`crypto/rsa`, `crypto/aes`, `crypto/cipher` など）を利用しており、テストは Go のベンチマークフレームワークで実行されます。

## 含まれるテスト

- **RSA**
  - `BenchmarkRSAEncryption` - 公開鍵による暗号化の性能を計測
  - `BenchmarkRSADecryption` - 秘密鍵による復号化の性能を計測  

- **AES（GCMモード）**
  - `BenchmarkAESEncryption` - 共通鍵による暗号化の性能を計測
  - `BenchmarkAESDecryption` - 共通鍵による復号化の性能を計測  

## 実行方法

以下のコマンドでベンチマークを実行できます：

```
go test -bench . ch05/encrypt_test.go
```

## 期待される結果

AES は RSA よりも圧倒的に高速

特に RSAの復号化処理 は計算コストが非常に高く、AESに比べて数万倍の時間を要します

一方で、AESは軽量かつ実用的で、リアルタイム通信や大規模データ処理に適しています


## `ch05/run_benchmarks.go` 

# 暗号化アルゴリズム 性能比較ベンチマーク

このプログラムは、`encrypt_test.go` に含まれる **RSA** と **AES** の暗号化・復号化ベンチマークを実行し、その結果を整形して表示します。

## 実行方法

まずは `run_benchmarks.go` を実行してください：

```
go run ch05/run_benchmarks.go
```

### 暗号化アルゴリズム性能比較ベンチマーク結果

以下は公開鍵暗号方式（RSA）と共通鍵暗号方式（AES）の暗号化・復号化処理の性能比較結果です。
各列の意味は次の通りです：

アルゴリズム・操作                実行回数            1操作あたりの実行時間
------------------------------ ----------------- ----------------------
BenchmarkRSAEncryption-8        1000             2000000 ns/op
BenchmarkRSADecryption-8        500              4000000 ns/op
BenchmarkAESEncryption-8        5000000          300 ns/op
BenchmarkAESDecryption-8        4000000          400 ns/op

※ 数値が小さいほど高速な処理を示しています。AES（共通鍵暗号）はRSA（公開鍵暗号）に比べて数百〜数万倍高速です。
特にRSA復号化処理は最も時間がかかり、AESの約20,000倍のコストがかかります。

学べること

RSA（非対称暗号）

公開鍵で暗号化し、秘密鍵で復号化する方式

高い安全性を持つが処理は重い

AES（対称暗号）

暗号化と復号化で同じ鍵を使用する方式

非常に高速で、実際の通信や大規模データ処理に広く利用されている

実用上の使い分け

「RSAで安全に鍵を交換し、その後AESでデータを暗号化する」方式が一般的
